# Current task router

The current user request, issue, or pull request defines the active task.

No unchecked item from a prior round is automatically active. The pre-cleanup task ledger is preserved at `docs/history/tasks-ledger-pre-token-cleanup-2026-08-26.md` for reference.

Use these entry points only when relevant:

- Current operating state and owner gates: `docs/CURRENT.md`
- Deployment and rollback: `docs/DEPLOYMENT.md`
- Redirects and SEO: `docs/redirects.md`
- Visual work: `docs/DESIGN_TOOLKIT_AI_CODER.md`
- Social asset work: `social/START-HERE.md`

Do not read the historical task ledger to discover work. Start from the request in front of you.
