## Deployment checklist

1. Deploy branch `social-toolkit-2026` to a protected preview.
2. Set `PREVIEW_PASSWORD=Patticake4000` or a replacement approved by the owner.
3. Leave `PREVIEW_PROTECTION_ENABLED` unset or set to `true` on shared environments.
4. Confirm the production nationwide order URL in `NEXT_PUBLIC_PATTICAKE_NATIONAL_ORDER_URL`.
5. Confirm inquiry/newsletter backends and production analytics destinations.
6. Review `/preview`, `/`, `/patticake`, `/yum-kitchen`, and `/asset-gallery` before promoting.

Run `bash scripts/check-repo-freshness.sh` before any future work. It enforces the canonical Zach checkout and fails when the active branch is behind `origin/main`.
